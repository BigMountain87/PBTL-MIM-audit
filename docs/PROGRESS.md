## 기록 규칙

1. 한 번에 한 태스크. `depends_on`의 모든 id가 `done`일 때만 착수한다.
2. 태스크마다 PLAN_v10.md의 「Sonnet 5 지시문」과 「검증」, `docs/plan_v10_raw.json`의 gap 근거를 읽고 그대로 실행한다.
3. verify 통과 → `git commit -m "Txx: <title>"` → 이 표의 status/date/commit/verify result를 같은 커밋에서 갱신.
4. verify 실패 시 수정 후 재실행. 해결 불가면 `blocked`으로 기록하고 저자에게 보고. 절대 `done`으로 표시하지 않는다.
5. 「저자 결정/검토」 줄이 있는 태스크는 기계적 부분만 수행하고 정지, 저자에게 선택지를 제시한다. §3 Day-8 결정 게이트는 저자의 몫.
6. `paper/manuscript_v9.md`는 편집 금지. `results_v8/`의 기존 seed-42 산출물은 변경 금지 (새 실행은 새 tag/파일명).
7. 원고에 들어가는 모든 수치는 JSON/CSV 아티팩트에서 읽는다. 기억에 의존하지 않는다.
